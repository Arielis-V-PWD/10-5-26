Space Picture API

Fetches NASA’s Astronomy Picture of the Day data for a selected date.

Endpoint

GET /api/space

Optional query

?date=2026-11-02

Example response

{ "title": "Example title", "date": "2026-11-02", "imageUrl": "...", "description": "..." }
